# 用户画像维护规则

## 边界

- 语义未变化或包含可直接使用的敏感值时不修改画像，表达不明确时询问用户。
- 用户画像只通过 agentbrain 工具维护，AI 不直接编辑生效文件。

## 新增

- 用户明确提出新的全局偏好，且画像中没有同义字段：调用 `memory_profile_set(key, value, reason)`，成功后简短反馈。
- AI 根据行为推测新的全局偏好：调用 `memory_profile_suggest(key, value, reason)`，展示候选并询问用户；确认后调用 `memory_profile_apply(suggestion_id)`，否定时调用 `memory_profile_reject(suggestion_id, reason)`。

## 修改

1. 调用 `memory_profile_history(key)` 查看原值和历史。
2. 调用 `memory_profile_suggest(key, value, reason)` 生成候选。
3. 向用户展示原值、建议值和修改原因，并询问是否修改。即使用户已明确给出新值，也不得省略本次确认。
4. 用户确认后调用 `memory_profile_apply(suggestion_id)`；否定时调用 `memory_profile_reject(suggestion_id, reason)`。

## 删除

1. 调用 `memory_profile_history(key)`，展示原值并询问是否删除。
2. 用户确认后调用 `memory_profile_remove(key, reason)`；未确认不得删除。

## 工具

| 工具 | 用途 | 参数怎么填 |
|---|---|---|
| `memory_profile_set` | 新增用户明确提出且不存在的全局字段 | key=字段名（必填）；value=字段值（必填）；reason=设置原因（可选） |
| `memory_profile_suggest` | 提交新增或修改候选 | key=字段名（必填）；value=建议值（必填）；reason=建议原因（可选） |
| `memory_profile_apply` | 用户确认后应用候选 | suggestion_id=候选编号（必填，suggest 返回的编号） |
| `memory_profile_reject` | 用户否定后归档候选 | suggestion_id=候选编号（必填）；reason=否定原因（可选） |
| `memory_profile_remove` | 用户确认后删除已有字段 | key=字段名（必填）；reason=删除原因（可选） |
| `memory_profile_history` | 查看字段原值和修改历史 | key=字段名（可选，不传查全部） |

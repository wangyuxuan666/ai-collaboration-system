# 经验维护规则

## 新增

1. 写入前检索相近记忆；已有内容发生变化时修正原 Lesson，没有才新增。
2. 查看[记忆索引](../agentbrain/Case-Learnings/Index.md)：能匹配已有 `case_id` 就沿用，不能匹配再按现有中文主题词风格新增。
3. **写入确认（两类）**：
   - **空白回答类**（用户对空白问题的回答/选择，见[经验入口](./入口.md)"空白处理闭环"）：回答本身视为确认授权，直接调用 `memory_ingest` / `memory_profile_set` 落库，不再二次贴稿确认；
   - **其他类**（AI 自发观察、主动沉淀的教训）：先把拟写入的完整内容（lesson 全文或偏好文案）贴给用户过目，用户明确确认后才可落库；未经确认不得调用。
4. 调用 `memory_ingest`。lesson 使用经验教训 / 适用场景 / 规避方案三段式；新增默认 confidence 为 0.5，用户明确要求“记住/以后都这样”时为 0.9。工具拒绝缺段、空段、敏感值，并将 confidence 限制在 0.1～1.0；新增不等于已验证。
5. 工具提示疑似重复时，带建议询问用户保留两条或修正合并；其他情况只反馈：`已记住：<摘要>（<类别>）`。

## 修正

用户撤销、推翻或补充已有偏好或做法时，修正原 Lesson，不新增同义记忆。

1. 调用 `memory_history(lesson_id)` 查看变化趋势。
2. 内容稳定、只是补充边界时，confidence 保持或按反馈校准；同一内容反转两次及以上时下调至 0.1，后续命中必须询问。
3. **修正确认**：用户直接纠正/改主意（推翻某条空白答案或经验）时，其纠正视为确认，直接调用 `memory_revise`；AI 主动发现需修正时，先把新旧对比贴给用户，确认后才调用。
4. 调用 `memory_revise`，提供最新三段式内容、变更摘要、原因，以及需要变化的 confidence、标签或摘要。
5. 原 ID 不变、历史保留，当前版本重新进入待验证状态；反馈：`已修正：<摘要>（v<版本号>）`。

## 合并与维护

- `memory_lint` 和 `memory_distill` 不在普通任务中自动运行；distill 只根据成功使用记录提炼，不根据写入次数判断成熟度。
- `memory_lint` 发现重复后，向用户展示保留项、归档项和原因。确认后调用 `memory_consolidation_apply(proposal)`，只标记 superseded 并归档提案，不物理删除文件或历史。
- Lesson 中产生的客观专业结论按[知识写入规范](../../知识库/规范/知识写入规范.md)处理，不与经验重复。

## 工具

| 工具                           | 用途                    | 参数怎么填                                                                                                                                                     |
| ---------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `memory_ingest`              | 新增 Lesson             | case_id=中文主题词（如"沟通"）：属已有主题就沿用，全新主题按风格新起，完整 id 自动排号；lesson=必填，三段式（经验教训/适用场景/规避方案）；tags=可选，主题标签逗号分隔；confidence=0.5，用户说"记住"则 0.9；source_summary=可选，摘要，不填自动截取 |
| `memory_history`             | 查看修订历史                | lesson_id=经验编号（形如 `沟通-lesson-01`），必填                                                                                                                                   |
| `memory_revise`              | 修正原 Lesson            | lesson_id=原经验编号（必填，修正不变）；lesson=必填，最新三段式全文；change=必填，变更摘要；reason=必填，原因；confidence=可选，按反馈校准；tags=可选，主题标签；source_summary=可选，摘要                                    |
| `memory_lint`                | 按需检查重复、过期和低置信度        | 直接调用，不传参                                                                                                                                                  |
| `memory_consolidation_apply` | 用户确认后执行 Lesson 合并归档提案 | proposal=lint 生成的提案原样传回                                                                                                                                   |
| `memory_distill`             | 按成功使用记录生成提炼建议         | 直接调用，不传参                                                                                                                                                  |

新增或修正的参数不确定，或工具因参数拒绝时，读取[Lesson 调用示例](./参考/Lesson调用示例.md)；其他情况不读。

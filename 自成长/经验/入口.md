# 经验入口

经验用于在相似任务和动作中复用已记录的协作做法与教训，减少重复试错。

本入口每个窗口读取一次即可，规则持续生效；重点见下方"首次检索"与"动作前检索"。

## 概念

- **Lesson（经验）**：一条可复用的经验记录，正文固定三段：经验教训 / 适用场景 / 规避方案。
- **lesson_id**：经验编号，形如 `沟通-lesson-01`（主题词-序号），全库唯一，修正时不变。
- **case_id（主题词）**：经验主题分类，如 `沟通`、`通用`；同一主题的多条经验共用一个主题词。
- **置信度 confidence**：经验可信度，取值 0.1～1.0；0.5 一般、0.9 用户强信任、0.1 不稳定；命中时按[采用与反馈](./采用与反馈.md)决定是否直接采用。
- **记忆索引**：`自成长/agentbrain/Case-Learnings/Index.md`，全部经验的目录表，用于查主题词和编号。

## 首次检索（收到任务后必做）

收到首个具体任务后，先扫一遍经验索引（`自成长/agentbrain/Case-Learnings/Index.md`，本地读取，成本低），了解已有经验的方面（case_id/标签）；再按任务类型执行一次动作前检索（见下方"动作前检索"），**简要说明检索结果**；未检索不开始任务主体工作。

## 空白处理闭环（有空白时执行）

- **空白**：任务中任何未确认的信息、取舍、默认值（需求、设计、方案、内容等），不得默认填补。
- 处理顺序（只列主干，细节按引用文件执行）：
  1. 查记忆：调用 `memory_query` 查经验、`memory_profile` 查画像；命中后按[采用与反馈](./采用与反馈.md)的置信度决定"直接用"或"先确认"；
  2. 未命中 → 识别为空白，分级：
     - 影响结果的取舍 → 进问题清单问用户（攒批问，一次给全）；问法=开放式 + 候选（2~4 个有区分度），每个候选标 token 消耗级别 + 优缺点 + 推荐（按[Token 消耗级别](../../协作入口/规范/Token消耗级别.md)标注）；
     - 低风险、可逆的小空白 → 自行决定并标注"这里我默认了 X，不满意说一声"；
  3. 回答即记：用户回答视为写入授权，按性质入画像（全局偏好）或经验（场景做法），写入按[维护规则](./维护规则.md) / [用户画像维护规则](../用户画像/维护规则.md)执行（无需二次确认）；
  4. 复用：后续同类空白先查记忆，命中即用，不再重复问；
  5. 反馈（强制）：使用记忆/空白答案后按[采用与反馈](./采用与反馈.md)执行 `memory_feedback`，用对用错都记；
  6. 不满意归因：用户不满意时，按[采用与反馈](./采用与反馈.md)"冲突与归因"定位空白来源（默认值/记忆/用户答的）并纠正；
  7. 优先级：本闭环与"一次只问一个问题"等经验冲突时，以本闭环为准（拍板类空白攒批问）。

## 动作前检索

1. 复合任务先拆成有效动作链，拆分本身不触发检索；每个动作用"动作类型 + 对象 + 预期产出"标识，只进入马上执行的一项。
2. 每个有效动作前，先对照已扫的经验索引（Index.md 的 case_id/标签/摘要）判断该动作类型是否有相关经验主题：**有 → 执行检索；没有 → 跳过**，不空查（[检索名单](./检索名单.md)的免查场景仍适用）。
3. 检索调用 `memory_query`，query 写明当前动作类型、对象和预期产出；先用 `mode=index, top_k=5` 获取候选，候选会影响行动时再用 `mode=full` 读取最相关的 1～3 条。
4. 查询只表示找到，不算使用，不改变使用次数或 confidence。命中 Lesson 时读取[采用与反馈](./采用与反馈.md)，再决定是否采用。
5. 动作完成后确定下一有效动作并重复本流程，不提前查询后续动作。

## 动作边界

- 有效动作是会形成新判断、新产出或实际修改的独立阶段，如查资料、分析文件、设计方案、修改内容和验证结果。
- 动作类型、对象或预期产出任一项明显变化，就进入新动作。同一动作只检索一次。
- 例如“网上查资料并优化文档”拆为“查询 → 阅读 → 形成方案 → 修改 → 验证”，每个动作分别判断名单并查询 Lesson。
- 连续搜索、读取同组文件、翻页和命令重试等同类操作仍属于同一动作，不重复检索。
- 检索名单判断、记忆查询、读取命中、反馈和记忆维护不触发新的检索。
- 证据不足，或影响扩大到公共组件、跨端接口、架构、权限、安全、数据一致性等范围时，可说明关系后扩大检索，不递归加载无关内容。

## 按需入口

- 记忆检索工具缺失或调用受阻时，按[Agent适配 MCP 强制要求](../../协作入口/Agent适配/README.md)向用户报告并暂停询问，不得静默跳过检索继续执行。
- Lesson 实际改变行动，或命中内容存在冲突、错误时，按[采用与反馈](./采用与反馈.md)处理。
- 产生、修正、合并或维护 Lesson 时，按[维护规则](./维护规则.md)处理。

## 工具

| 工具 | 用途 | 参数怎么填 |
|---|---|---|
| `memory_query` | 检索经验 | query=必填，写明当前动作类型、对象和预期产出；mode=index 返回摘要候选、full 返回全文；top_k=候选条数，默认 5 |

## 必读（每次会话）

开始任何任务前，先按顺序读完以下 4 个文件，未全部读完不得开始任务；开始任务前确认已全部读取。

- 自成长记忆入口：[自成长入口](../自成长/入口.md)
- Agent适配：[Agent适配](./Agent适配/README.md)
- MCP登记：[MCP登记](../工具/MCP/README.md)
- Token 消耗级别：[Token 消耗级别](./规范/Token消耗级别.md)

## 角色触发预判

读取用户首条消息时，检查是否存在角色赋予表达，例如“你现在是……”“你担任……”“请以……身份负责”或“由……来处理”。

若存在此类表达，不判断角色名称是否已知，立即读取[角色入口](../角色/入口.md)，由角色入口核对登记角色并启动对应角色。

## 通用按需读取规则

所有标记为“按需”的文件统一遵守：

1. 用户输入、当前任务或当前动作满足某个文件的触发条件时，立即读取该文件；未满足时不读取。
2. 必要文件未读取完成前，不得执行该文件约束的动作、修改文件或创建窗口。
3. 命中多个文件时，按当前动作的依赖顺序读取。
4. 读取完成后继续当前任务，不因读取动作停住；后续动作按同一规则继续判断。
5. 各入口只声明自身触发条件，不在总入口重复列举具体文件或场景。

## 按需入口索引

以下文件均为按需入口；是否读取由各文件自身声明的触发条件决定：

- 任务需要提交知识候选、使用已确认的知识或规范、查找原始材料或维护知识库时，读取[知识库入口](../知识库/入口.md)。
- 用户讨论、评价、设计、优化、修改、整理、迁移或维护 AI 协作体系时，读取[维护方针](./AI协作体系维护/AI协作体系维护方针.md)。
- 执行复杂或迭代任务、需要自检与终态判断、选择执行强度或处理询问反馈边界时，读取[通用执行规范](./规范/通用执行规范.md)。
- 建立节点、接手复杂任务或跨窗口交接时，读取[上下文管理规范](./规范/上下文管理规范.md)。
- 任务过程中发现问题、犯错、形成可复用结论或发现规则/文件缺口（含任务完成阶段对产出与结论的复查），**以及用户当场纠正你、说你错了、或同一点又说了一遍时**，先判断这些内容该记到哪里、是否该建议修改协作体；命中任一即**必须读取**[记录分流入口](./记录分流/入口.md)判断去向，不得凭感觉跳过或自行消化。
- 需要新增、接入、修改或排查 MCP,skill,或安装/接入自带工具或技能的平台插件时，**必须先读取**[MCP与Skill接入规范](./规范/MCP与Skill接入规范.md)并按规范执行。

## 任务边界

- 改变目标、范围、优先级、验收或权限，以及执行高风险操作前，先与用户确认；删除、覆盖、批量修改等不可逆操作执行前，先说明影响再确认。
- 判断任务是否完成时，以实际交付物和验证证据为准，并说明已知风险。

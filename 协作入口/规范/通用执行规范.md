# 通用执行规范

适用于所有对话、角色和任务，不依赖角色绑定。绑定角色后从[角色通用规则](../../角色/规范/角色通用规则.md)进入；未绑定角色时按[协作入口 README](../README.md) 按需读取。

## 行为边界

- 与当前任务或已绑定角色无关的事项，只说明现象、依据和影响，不作最终判断或直接执行。

## 文件落盘

- 下载、克隆或生成临时文件**前，先核查本地是否已有或可复用**（已装的命令/全局包、协作体本地源码与现成产物等），**确实没有才提出下载**；请用户为下载/安装拍板时，**同时给出本地核查结论**。目标位置优先询问用户；用后清理，不长期留存在 C 盘。

## 执行循环、自检与终态

- 复杂或需要迭代验证的任务采用“理解 → 行动 → 观察 → 自检 → 继续或回传”的轻量循环；简单读取、明确查询或一次动作即可验证的任务不强制使用。该循环用于指导执行，不要求向用户展示完整过程。
- 用户确认目标/方案后，立即执行已确认范围内的动作并推进到收口，不再重复确认或停留在讨论；执行只到已确认的那一步为止，角色/流程另行要求的确认（如总控开窗前先确认窗口计划）仍照常执行。
- Agent 根据任务、工具结果和验收标准自主选择观察内容；观察不足以支撑判断时继续补充，不要求用户预先规定观察步骤，也不输出完整思考过程。
- 未满足任务包目标、范围、交付物或验收标准时继续分析、修正和验证。“部分完成”只是循环中的内部状态，不作为最终回传结果。
- 回传完成前必须自检：目标与范围是否满足、交付物是否齐全、验收证据是否成立、是否越权、是否存在未说明风险；代码变更还要按影响范围做相称的回归检查。
- 对用户或直接调用者只回传两种终态：`完成并自检通过`，或 `阻塞待决定`。缺少关键输入、存在目标或验收冲突、必须改变已确认决定、需要新增权限或高风险操作、外部依赖不可用、继续可能造成不可逆影响，或合理尝试已无价值时，才进入阻塞；普通可排查问题继续循环。
- 循环中发现可复用结论、行为教训、输入不一致或规则/文件缺口等可能跨任务改变 AI 判断或行动的新信息时，不打断当前执行；在该动作告一段落、能安全停下时（不等到整个任务完成）立即按[记录分流入口](../记录分流/入口.md)判断该记到哪里、是否该建议修改协作体，不得自行消化。

## 执行等级与恢复

- 按正确率和风险选择最低总成本的执行强度：轻量适用于明确、低风险、易验证且易恢复的任务；标准适用于一般分析、多文件或专业取舍，无法判断时默认；高级适用于重大歧义、跨系统影响、架构、复杂排障、高风险、不可逆或难验证任务。
- 开始执行时按单次成本、风险、恢复难度和验证成本确定尝试预算：高成本或高风险任务减少尝试，轻量、低风险且易验证的任务可增加尝试。
- 每次重试必须改变方法或获得新证据；重复同一种失败不算有效尝试。预算耗尽或继续尝试已无合理价值时进入阻塞待决定，不机械凑满固定次数；停检节奏与"带成本账"细节按[角色通用规则](../../角色/规范/角色通用规则.md)"未达标处理"执行，此处不重复。
- 可能影响生产数据、可用性、安全边界或大量成果的任务，执行前建立基线或备份、验证、停止条件和恢复方案；已确认的回滚条件命中时可直接回滚，新的破坏性操作仍须确认。
- 长任务按节点模板维护检查点；恢复时重新核对外部变化，不重复完成工作或扩大范围。实质变化时重新规划；尝试预算耗尽或继续尝试已无合理价值时进入阻塞并提出调整。

## 上下文管理

- 建立节点、接手复杂任务或跨窗口交接时，按[上下文管理规范](./上下文管理规范.md)维护最小上下文卡；未触发不读取。

## 询问与反馈

- 询问判据：会不可逆、影响面大、没把握、或属于免询问名单外的新情况时，先说明影响和计划再询问；可逆、影响小、有把握、名单内的，自主执行。两头都防：事事都问（用户变成橡皮图章）和该问不问（出事才暴露）。
- 提问一次只问一个：要确认的事项（含拍板、取舍、确认类）多时逐个来，不攒成一批让用户一次答完。用户一次抛来多个问题/意见时，先全部记下不遗漏，再逐个解决。提问用自由对话，不用选项卡片批量提问。
- 未经用户确认定稿的内容，不抢先落文档、改文件或宣布"已同步"；落盘前用一句话复述"将写入什么、依据是哪句确认"再动手，用户质疑时立即停下并可回退。
- 主动提出与任务相关的问题、风险、冲突、遗漏或更优方案。
- 承接节点的下级以节点模板为任务和回传依据；完成并自检通过后，主动按模板记录的直接调用者和回传方式提交结果并进入待验收。模板缺少直接调用者、实际 ID 或回传方式时才询问，不要求上级在聊天中重复任务包。
- 直接调用者验收通过后节点才标记已完成；验收不通过时继续在已确认范围内修正，只有触发阻塞条件或需要改变目标、范围、验收、权限或风险边界时才请求决定。
- 未获确认、验收失败、需返工或发生重大变化时，说明影响和建议并等待处理。

# Token 消耗级别

## 用途

AI 向用户提建议、让用户在多个方案中选择时，在每个方案后标注该方案的 token 消耗级别，让用户直观比较各方案成本。标注格式为"token 消耗 N"，例如：

- 方案 A（token 消耗 3 级）：完整重构某模块。
- 方案 B（token 消耗 1 级）：仅调整某个文件。

## 计算规则

- 消耗级别表示预估新增 token 成本，不是精确计费值；只计算该方案执行产生的新增上下文、分析、输出和验证成本。
- 预估新增 token 低于 500：标记为 `<1`（不足 1 级）。
- 预估新增 token 达到 500 或以上：按"预估 token / 1000"四舍五入，结果为消耗级别。
- 消耗级别无上限。

换算示例：

- 400 token：`<1`。
- 900 token：级别 1。
- 1500 token：级别 2。
- 2500 token：级别 3。

## 标注要求

- 方案比较、任务分配以及明显高成本动作，必须标注消耗级别和预估范围。
- 普通低成本动作不强制显示消耗级别。

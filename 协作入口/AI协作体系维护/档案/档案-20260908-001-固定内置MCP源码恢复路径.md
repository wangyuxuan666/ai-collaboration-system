## 结论
一句话：工具恢复时，已随协作体提供的 MCP 必须直接使用文档规定的固定源码路径，不搜索、不下载、不重复安装；仅在源码缺失时报告协作体不完整。

## 为什么
1. 协作体内已包含 agentbrain MCP 源码，AI 因未注册或命令不在 PATH 而重复安装，会造成多份源码和版本来源不一致。
2. 原规则没有明确“现有源码未接入”和“源码本身缺失”的区别，也没有明确恢复期间可以继续执行接入排查。
3. 用户要求工具不可用时 AI 按需读取当前 Agent 的 MCP 接入说明并自行恢复，只有需要外部安装、重启或更高权限时才请求确认。

## 影响范围
- `协作入口/Agent适配/README.md`：明确固定路径优先、禁止重复安装、恢复期间暂停范围和授权边界。
- `协作入口/Agent适配/Codex/入口规则.md`：明确工具缺失时继续执行允许的恢复动作。
- `协作入口/Agent适配/Codex/MCP接入.md`：明确 agentbrain 源码和记忆库的固定路径及源码缺失处理。
- `工具/MCP/安装指引.md`：明确 agentbrain 源码随协作体提供且不得另行安装。

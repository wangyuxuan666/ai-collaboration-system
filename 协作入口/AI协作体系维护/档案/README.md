# 档案

档案记录**体系规则的决策历史**：为什么这么定、后来改过啥。它只记"规则的理由与变更"，不记经验教训（经验归 agentbrain）、知识内容（归知识库）、用户偏好（归画像）。

## 什么时候写

- 规则新增 / 修改 / 废弃（会改变 AI 后续行为的体系规则或机制）→ 由触发窗口写。
- 新增：建一条档案；修改：在原档案"后续变更"追加一行；废弃：状态改"已弃置"或"已替代"。
- 只记规则，不记：知识库内容、画像偏好、经验教训、日常任务产出。

## 编号规则

文件名 = `档案-YYYYMMDD-NNN-标题.md`，NNN 为当天三位序号：

- 写前用 glob 查当天已有 `档案-YYYYMMDD-*`，取最大序号 +1。
- 标题必含规则关键词（如"引入档案机制""Token消耗级别调整"），让人一眼看出是哪条规则。

## 模板

```
状态：已接受      ← 提议 / 已接受 / 已弃置 / 已替代
日期：YYYY-MM-DD
触发窗口：DSH
关联经验：成长机制-lesson-04   ← 可空、可多个，填 lesson_id
替代者：档案-xxx    ← 只有状态=已替代才填

## 结论
一句话：这次定了啥

## 为什么
1. 理由

## 影响范围
改了哪些文件/规则

## 后续变更
（以后修改就追加一行：日期 + 从啥改成啥 + 为啥）
```

## 怎么找

- 按编号：glob 精确匹配 `档案-20260827-*`。
- 按关联经验：grep 搜 lesson_id（如"成长机制-lesson-04"）。
- 不整库翻阅。

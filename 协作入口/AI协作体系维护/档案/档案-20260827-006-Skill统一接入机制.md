## 结论
引入 Skill 统一接入机制：skill 源码统一存放 `工具/skills/`（一份源码，各平台链接指向），每个 Agent 新增 skills接入.md 登记加载机制与排查链；"优化流程线"由三平台三份合并为通用一份；UA（Understand Anything）接入协作体作为代码开发协作 skill。

## 为什么
1. 用户要求 skill 源码放协作体文件夹（随文件夹走），各 Agent 通过链接指向同一份，不复制多份；换电脑带文件夹 + 重建链接即可。
2. UA 实际未装好（链接指向不存在的 F:\skill），需要修复并登记；UA 是 Skill 插件（非 MCP），安装脚本支持 Codex/Hermes，DSH 通过共享 ~/.agents/skills 自动发现。
3. 原有"优化流程线"三平台三份内容几乎相同，合并为通用版，平台差异下沉到各平台 skills接入.md，消除重复维护。
4. skill 不可用时需有明确处理路径（对齐 MCP 强制要求），不静默跳过。

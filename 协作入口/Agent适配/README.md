## 工具接入与故障处理 SOP（各平台通用）

触发：需要使用已登记 MCP/skill，但工具未出现或调用失败时，按下方 SOP 执行；未触发时不检查。

1. **排查**：判断原因——本机没装？还是装了但未链接/未生效？
2. **分支处理**：
   - 没装 → 查官方安装方式 → 向用户说明"装什么、装到哪、影响什么"→ 同意后安装 → 验证命令可用；
   - 装了但未链接/未生效 → 按本平台配置方式接入（各平台参数见对应 `MCP接入.md` / `skills接入.md`）→ 向用户说明"改什么、影响、如何验证"→ 同意后配置 → 重启/刷新平台。
3. **验证**：工具真实出现且成功调用才算完成；CLI 或脚本可运行不等于已接入。
4. **兜底**：失败时说明失败项、修复成本、替代方案，暂停等用户决定；不得静默跳过或用替代流程冒充；未完成接入或未暂停前不得继续原任务。

# DSH 入口规则

本文件只记录 DSH（DeepSeek Harness）平台的运行规则，并路由到按需接入文件。

## 身份与任务

- **承载单位**：当前 DSH 会话是角色身份和结果责任的承载单位。
- **节点与内部任务**：用户可见节点按角色线及节点模板规则承接；节点承接不得用后台子代理代替（见委派与子任务）。

## 委派与子任务

- **角色窗口（顶层独立会话）**：上级窗口创建下级角色窗口时，经平台 API（`session.create` + `session.prompt`，本地端点 `http://127.0.0.1:3080/api/<方法>`，UTF-8 载荷）创建**顶层独立会话**作为角色窗口载体——侧边栏可见、用户可直接对话，不隐藏、不依赖上级中转。**下级必须与上级在同一项目：创建载荷携带上级所属 workspace 的 `workspaceId`（不是 `cwd`），创建后核验与上级同分组。** 新窗口继承部署默认沙箱与审批策略；需要浏览器（bsk）等能力或更高权限时，由用户在该窗口授权。
- **跨窗口派发/回传调用格式**：`session.prompt`（POST `http://127.0.0.1:3080/api/session.prompt`，UTF-8 JSON）必须带信封：`{type:"client-request", rpcId:"<任意串>", method:"session.prompt", payload:{sessionId:"<目标会话>", mode:"queue", content:[{type:"text", text:"<消息>"}]}}`。裸 payload 会被拒（bad-request）；响应 `result.ok=true` 即送达。`127.0.0.1:3080` 指每个使用者自己运行的 DSH 实例，非特定机器。
- **子代理（subagent）**：仅承接限定子任务（非用户可见节点）；已规划的用户可见节点/角色窗口**不得用子代理代替**，按角色线及节点模板规则执行。

## 插件能力

任务命中下表场景时使用对应工具；工具缺失或调用失败时按下方[接入硬性检查点](#接入硬性检查点)处理，不自行改用未登记工具。新增场景及工具须经用户确认。

| 使用场景              | 触发条件                    | 使用工具                                   | 备注                       |
| ----------------- | ----------------------- | -------------------------------------- | ------------------------ |
| 搜索与网页读取           | 任务需要搜索网页、读取网页内容或查 X 内容时 | `read_page`（读网页/搜索结果页）、`x_search`（搜 X） | 由 modsearch 插件提供，用户已确认   |
| 浏览器操作             | 需要登录态、表单填写、动态页面交互或页面截图时 | 用时 read `./skills/browser-skill/README.md`，按步骤调 `bsk` 命令；该文件缺失/断链时按下方[接入硬性检查点](#接入硬性检查点)处理 | 由 bsk CLI + 浏览器扩展提供；DSH 专属 skill，使用/搭建/故障见该 README |
| 办公文档（Univer Office） | 任务需创建/读取/编辑/导入导出表格、文档、演示、Base、画板或处理 `.univer`/`.xlsx`/`.csv`/`.tsv`/`.docx`/`.pptx` 内容时 | `univer_*` 工具族（new/status/worktree/unit/import/inspect/execute/export/lint/compile_svg/screenshot/api/resources）；用时先 read 插件自带 skills 目录（`$DSH_HOME\profiles\web\node_modules\dsh-univer-office\skills\`）下对应 SKILL.md（univer-sheet/doc/slide/base/board 等） | 由 dsh-univer-office 插件（v0.2.10）提供，用户已确认；工具缺失时按下方[接入硬性检查点](#接入硬性检查点)处理 |
| （新增场景时在此追加，须用户确认） |                         |                                        |                          |

## 接入硬性检查点

- 需要调用已登记 MCP，但工具未出现或调用失败时，必须按[工具接入与故障处理 SOP](../README.md)执行；具体参数见 [MCP接入](./MCP接入.md)。完成接入或按 SOP 暂停前，不得继续任务，不得静默跳过，不得用 CLI 或脚本冒充 MCP。
- 需要调用已登记 skill，但缺失、断链或未发现时，必须按[工具接入与故障处理 SOP](../README.md)执行；具体参数见 [skills接入](./skills接入.md)。完成接入或按 SOP 暂停前，不得继续任务，不得静默跳过或使用替代流程。
- 未触发时不读取、不检查。

## 恢复

- 平台会话自动持久化（JSONL），关窗/重启后可从会话历史恢复上下文；平台不自动保留的（节点状态、交付物入口、授权决定等）按[上下文管理规范](../../规范/上下文管理规范.md)建立/更新最小上下文卡。

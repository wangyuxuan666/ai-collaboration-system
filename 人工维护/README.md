# 人工维护

本目录存放需要人工双击执行的维护脚本。**双击 `.bat` 直接执行（带控制台窗口）；双击 `.vbs` 直接弹出 GUI 窗口，无黑框。**

## 脚本索引

| 脚本 | 作用 | 运行后 |
|---|---|---|
| `可视化工作台更新数据.bat` | 可视化工作台数据刷新 | 扫描体系目录 → 重新生成 `工具\可视化工作台\data.js`（总览树数据）；生成前自动备份 data.js.bak，失败自动回滚 |

## 说明

- 工作台数据脚本只做只读扫描和数据刷新，不修改体系其他文件。
- agentbrain 记忆库维护不再需要人工脚本：lint（查重复/过期/无标签）直接在对话中让 AI 调用 `memory_lint` 工具完成。

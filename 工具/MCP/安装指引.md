# MCP 安装指引（按需读取）

本文件只在**需要安装、搭建或修复某个 MCP** 时读取；平时不读、不占上下文。登记清单见 [README](./README.md)，通用排查流程见[工具接入与故障处理 SOP](../../协作入口/Agent适配/README.md)。

## agentbrain（本地自成长记忆）

- **性质**：协作体修改版（非原版），源码随体系分发。
- **源码位置**：`记忆查询工具/agentbrain-main/`（本目录）。
- **版权**：Apache-2.0（原 LICENSE 见源码根目录），修改说明见 `CHANGES.md`。
- **依赖**：Python ≥ 3.10；`PYTHONPATH` 需包含 `agentbrain-main`、`agentbrain-main/.deps`、`.deps/win32/lib`、`.deps/win32`；环境变量 `AGENTBRAIN_VAULT` 指向记忆库（自成长数据目录）；`PYTHONIOENCODING=utf-8`。
- **安装步骤**：
  1. 确认源码已在 `记忆查询工具/agentbrain-main/`（随体系自带，无需下载）；
  2. 确认 Python 可用：`python --version`（≥3.10）；
  3. 补装依赖（如 `.deps` 缺失）：按源码 `pyproject.toml` 安装 `mcp`、`PyYAML` 等到 `.deps` 目录；
  4. 按当前 Agent 的接入文件注册为本地 stdio MCP（启动命令 `python -m agentbrain.cli serve`）。
- **验证**：重启后 `memory_profile`、`memory_query` 工具出现，各做一次只读调用成功。
- **原仓库**：https://github.com/2672243194/agentbrain （本目录为修改版，非原版）

## mcp-gitee（Gitee 仓库协作）

- **性质**：第三方官方 MCP Server，源码可本地构建或直接用远程官方服务。
- **源码/来源**：`git clone https://gitee.com/oschina/mcp-gitee.git`（协作体源码位置 `gitee/`，不在时按此下载）。
- **版权**：MIT（Copyright (c) 2025 Gitee，LICENSE 见源码目录）。
- **依赖**：Go（本地构建）或直接 npx/远程。
- **安装步骤**：
  1. 源码不在时：`git clone https://gitee.com/oschina/mcp-gitee.git 工具/MCP/gitee`；
  2. 构建或准备 `mcp-gitee` 可执行文件（`go build`，或官方 release）；
  3. 按当前 Agent 的接入文件注册本地 stdio MCP；`env` 设 `ENABLED_TOOLSETS=list_user_repos,create_repo,get_user_info` 只暴露 3 个工具；
  4. `GITEE_ACCESS_TOKEN` 从环境变量继承，不写入明文令牌。
- **验证**：重启后 3 个工具出现，做一次只读调用（如 `get_user_info`）。
- **远程备选**：`https://api.gitee.com/mcp`（免部署，官方全量 29 工具，无法过滤）。

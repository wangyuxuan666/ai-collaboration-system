# MCP 安装指引（按需读取）

本文件只在**需要安装、搭建或修复某个 MCP** 时读取；平时不读、不占上下文。登记清单见 [README](./README.md)，通用排查流程见[工具接入与故障处理 SOP](../../协作入口/Agent适配/README.md)。

## agentbrain（本地自成长记忆）

- **性质**：协作体修改版（非原版），源码随体系分发。
- **源码位置**：`记忆查询工具/agentbrain-main/`（本目录）。
- **版权**：Apache-2.0（原 LICENSE 见源码根目录），修改说明见 `CHANGES.md`。
- **依赖**：Python ≥ 3.10；`PYTHONPATH` 需包含 `agentbrain-main`、`agentbrain-main/.deps`、`.deps/win32/lib`、`.deps/win32`；环境变量 `AGENTBRAIN_VAULT` 指向记忆库（自成长数据目录）；`PYTHONIOENCODING=utf-8`。
- **安装步骤**：
  1. 确认源码已在 `记忆查询工具/agentbrain-main/`（随体系自带，无需下载）；
  2. 确认 Python 可用：`python --version`（≥3.10）；
  3. 补装依赖（如 `.deps` 缺失）：按源码 `pyproject.toml` 安装 `mcp`、`PyYAML` 等到 `.deps` 目录；
  4. 按当前 Agent 的接入文件注册为本地 stdio MCP（启动命令 `python -m agentbrain.cli serve`）。
- **验证**：重启后 `memory_profile`、`memory_query` 工具出现，各做一次只读调用成功。
- **原仓库**：https://github.com/2672243194/agentbrain （本目录为修改版，非原版）

## mcp-gitee（Gitee 仓库协作）

- **性质**：第三方官方 MCP Server（Gitee 出品），源码本地已带，可准备本地可执行文件，也可直接用远程官方服务。
- **源码位置**：`gitee/`（本目录）；不在时 `git clone https://gitee.com/oschina/mcp-gitee.git 工具/MCP/gitee`。（注：`工具/MCP/gitee/` 已加入 .gitignore、不随共享仓库分发；其他部署按此 clone 补源）
- **版权**：MIT（Copyright (c) 2025 Gitee，LICENSE 见源码目录）。
- **可执行文件准备（无 Go 也能装；落点先与用户确认，按用户"不写 C 盘"等偏好选择，不在共享文档写死路径），三选一**：
  1. npm 官方包装包（免编译）：进入 `gitee\npm\mcp-gitee\` 执行 `npm install`，自动下载当前平台的官方二进制；装完按实际生成的命令/路径注册（该目录是官方 `@gitee/mcp-gitee` 包源码）。
  2. 官方 release 二进制：从 Gitee `oschina/mcp-gitee` 的 release 下载对应平台版本并解压到目标目录。
  3. 本地编译：`go build`（需先在本机装 Go）。
- **下载/安装前**：先向用户说明下载内容、来源、安装位置与影响并取得同意。
- **注册**：按当前 Agent 的 `MCP接入.md` 注册为本地 stdio MCP（DSH 见[协作入口/Agent适配/DSH/MCP接入.md](../../协作入口/Agent适配/DSH/MCP接入.md)）；`env` 设 `ENABLED_TOOLSETS=list_user_repos,create_repo,get_user_info`，只暴露这 3 个工具。
- **凭据**：`GITEE_ACCESS_TOKEN` 注入方式按当前 Agent 的 `MCP接入.md` 执行；不在任何文件、日志中写入明文令牌。首次接入先创建 token：Gitee 网页「设置 → 安全设置 → 私人令牌」新建并勾选仓库相关权限；值只设入 Windows 用户环境变量 `GITEE_ACCESS_TOKEN`（或按当前 Agent 的 `MCP接入.md` 要求），不落任何文件。
- **验证**：工具出现后做一次只读调用（如 `get_user_info`）。
- **远程备选**：`https://api.gitee.com/mcp`（免部署，官方全量 29 工具，无法过滤）。

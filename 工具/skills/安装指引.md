本文件只在**需要安装、搭建或修复某个 skill** 时读取；平时不读、不占上下文。skill 登记与使用点见 [README](./README.md)，通用排查流程见[工具接入与故障处理 SOP](../../协作入口/Agent适配/README.md)。

## 优化流程线（协作体自建，体系优化）

- **性质**：原创 skill，源码随体系分发，无需安装。
- **源码位置**：`体系优化/优化流程线/SKILL.md`。
- **版权**：本协作体原创。
- **安装步骤**：无（随体系自带）；按当前 Agent 的 skills 接入方式登记链接即可。
- **验证**：按维护方针 Skill 索引能 read 到 `SKILL.md`。

## UA（Understand Anything，代码理解/知识图谱）

- **性质**：第三方开源 skill 仓库（代码开发协作工具）。
- **源码/来源**：`git clone https://github.com/Egonex-AI/Understand-Anything.git`（协作体源码位置 `代码开发协作工具/Understand-Anything/`，不在时按此下载）。
- **版权**：MIT（Copyright (c) 2026 Yuxiang Lin，LICENSE 见源码目录）。
- **依赖**：Node ≥ 22、pnpm。
- **安装步骤**：
  1. 源码不在时：`git clone https://github.com/Egonex-AI/Understand-Anything.git 工具/skills/代码开发协作工具/Understand-Anything`；
  2. 装依赖：在源码目录跑 `pnpm install`（按源码 README 准备）；
  3. 按当前 Agent 的 skills 接入方式建立平台链接（Codex/Hermes 为 `~/.agents/skills` / `~/.hermes/skills` 下 understand 等链接，DSH 按需 read 源码 SKILL.md）。
- **验证**：能 read 到对应 `understand-*/SKILL.md`；需要平台工具时按官方 README 注册。
- **注意**：本协作体只用其源码 skill 部分，不运行官方 install.ps1 装 C 盘；平台链接指向工作区源码。

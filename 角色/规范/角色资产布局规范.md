# 角色资产布局规范

## 1. 适用范围

本文件定义角色核心文件、免询问文档、流程、专业领域、参考资料、资产目录、角色专属规范和角色专属模板的放置位置。角色内容、启动路由和各类文件正文仍由其各自负责的文件定义。

## 2. 标准结构

```text
角色\
├─ 角色列表\
│  └─ <职责分类>\
│     └─ <角色名称>\
│        ├─ <角色名称>.md
│        ├─ <角色名称>_免询问文档.md
│        ├─ 流程\
│        │  └─ <流程名称>.md
│        ├─ 专业领域\
│        │  └─ <专业领域名称>.md
│        ├─ 参考资料\
│        │  └─ <参考资料名称>.md
│        └─ 资产目录\
│           └─ <角色资产台账>.md
├─ 规范\
└─ 模板\
   └─ <职责分类>\
      └─ <角色名称>\
         └─ <角色专属模板>.md
```

## 3. 放置规则

- `<职责分类>`按角色主要负责的专业体系确定，不按管理职位、专业负责人职位或执行职位等职位类型确定。
- 角色核心文件、免询问文档、角色自有流程、专业领域内容、角色专用参考资料、角色专属规范和资产目录放在角色专属文件夹中；角色专属规范由角色入口、角色核心文件或角色流程按触发条件指向，不适用于所有角色的规范不放入角色通用规则。
- 角色专属模板放在 `角色\模板\<职责分类>\<角色名称>`，不放入角色专属文件夹。
- 多个角色共用的系统模板按其服务的体系和对象分类，不强行归入某个具体角色目录。
- 角色入口只登记角色核心文件，不登记流程、专业领域、参考资料、模板或免询问文档。
- 单个专业领域默认使用 `专业领域\<专业领域名称>.md`；确认需要多个文件时，改用 `专业领域\<专业领域名称>\` 子目录保存该领域内容。
- 每个角色都必须创建“流程”“专业领域”“参考资料”“资产目录”四个目录，即使暂时没有对应内容；空目录中不创建占位文件。
- “参考资料”只保存角色完成特定任务时需要查阅的角色专用资料，不保存系统共享的正式产物，也不代替 Wiki、专业领域或流程；系统共享的正式文件保存在其所属系统目录中，角色需要使用时只登记准确入口，不在“参考资料”目录中复制一份。
- “资产目录”保存角色持续维护的外部或运行资产台账、状态和定位信息，例如 Git 管理员的 Gitee 资产目录；不保存项目交付物、流程正文、参考资料或 Wiki 内容。建立或更新资产台账前，说明对象、价值、字段和位置并取得确认；记录保留来源、状态和更新时间。
- 角色核心文件登记资产目录和参考资料的准确入口与适用场景；资产目录入口登记在"启动时必须读取的内容"章节，参考资料按任务需要读取、不在角色启动时默认加载。
- 文件之间只登记必要的准确路径或接口，不复制由其他文件负责的规则或正文。
- 角色规范只有在用户确认具体规则、适用范围和主要影响后才启用；规范内容至少说明规则、适用条件、例外、确认依据和演变。

## 4. 创建与优化

- 创建角色时根据已确认的角色职责选择职责分类，并按本规范生成已确认需要的资产。
- 优化角色时保持现有有效结构；只有职责分类或资产归属确需改变且用户确认后，才移动文件并同步更新全部受影响路径。
- 发现现有结构与本规范不一致时，先判断迁移影响，不因格式统一而擅自移动已有文件。

# 代码开发验证核对表（检查项归属总览）

一张表列出代码开发要检查的点、每个点归谁查、在哪个环节查。各角色执行本表标给自己角色的行；**检查点归属以本表为准**，各角色文件与流程不重复抄清单，需要时引用本表对应行。

## 使用说明

- **归属**：开发自测 = 执行角色（前端/后端开发）交付前自查；负责人验收 = 对应领域负责人（前端负责人验收前端项、后端负责人验收后端项）；独立测试 = 测试工程师；总控 = 项目最终验收与上线放行核对。技术经理在整体技术验收时做跨端核对（见"跨端契约与联调"行）。
- **适用**：通用 = 前后端都要查；前端 = 仅前端负责人/前端开发查；后端 = 仅后端负责人/后端开发查。
- **环节**：模块开发 / 模块验收 / 整体验收 / 上线前。表内"模块开发/验收"表示该点从开发自测到模块验收都要查；"整体/上线前"表示整体验收和上线前放行都要查；"上线前"仅总控最终验收放行时查。
- **模块级 vs 整体级**：模块级只核对"模块验收"环节标给负责人的行（轻查：契约、可靠性、对接正确）；整体/上线前按全量行核对，含量化指标与交付证据。验收流程的执行展开见[前端交付验收](../../角色列表/软件研发/开发/前端/前端负责人/流程/前端交付验收.md)与[后端交付验收](../../角色列表/软件研发/开发/后端/后端负责人/流程/后端交付验收.md)。

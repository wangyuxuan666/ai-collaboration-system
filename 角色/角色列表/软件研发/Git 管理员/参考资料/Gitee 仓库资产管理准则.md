# Gitee 仓库资产管理准则

## 1. 凭据边界

- Gitee 账号密码、访问令牌、SSH 私钥和其他认证材料不得写入角色文件、项目文件、日志、提交历史或项目目录。
- 凭据仅通过操作系统受保护的凭据存储、Git Credential Manager、SSH 代理或其他可撤销的运行时机制使用。
- 优先使用权限最小、可设置有效期和可撤销的访问令牌或 SSH 密钥；凭据疑似泄露时立即撤销并替换。

## 2. 仓库资产治理

- 以项目组聚合业务项目，以独立仓库承载可独立维护的组件；仓库命名和项目目录共同提供可发现性。
- 仓库可见性、成员权限和归档状态应与当前项目状态一致；调整前确认影响范围。
- 项目目录应能定位每个组件仓库的职责、远程地址和本地首次拉取目录。

## 3. 交接边界

- 新仓库完成首次拉取和登记后，由后续开发或项目角色负责日常 Git 与版本协作操作。
- Git 管理员只在新增远程地址、整理仓库资产或调整 Gitee 侧设置时再次介入。

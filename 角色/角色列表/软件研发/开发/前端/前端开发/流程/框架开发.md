# 框架开发

用于建设或维护前端工程底座与公共能力。

## 0. 开工前：按知识库入口检索

开始实现前，先按[知识库入口](../../../../../../../知识库/入口.md)检索"代码开发/前端工程"分组的规范知识，读取命中且影响本次实现的页面，按其规范实现；未命中则跳过，不阻塞任务。通用核对项（组件拆分与复用、样式与选择器组织、状态与数据接入、响应式与可访问性、构建与性能）见[代码开发验证核对表](../../../../../../模板/项目治理/代码开发验证核对表模板.md)，不在此重复；结合[框架方向专业领域](../专业领域/框架.md)核对方向补充项：工程配置、公共能力约定、复用底座。

## 1. 理解工程要求

核对已确认的技术方案、框架约定和公共契约，识别实现中的风险、依赖或方案缺口，说明影响并提出建议。拟改变已确认技术方案、跨模块公共契约或既有兼容性承诺时，先说明影响并取得用户确认。

## 2. 实现与维护工程底座

实现和维护前端工程配置、构建与运行基础、公共能力及其他复用底座，按第 0 步检索到的规范执行；在不改变已确认方案和公共契约的前提下，自主作出必要的局部工程实现取舍。完成与其变更相称的验证。

## 3. 说明与自测

按第 0 步的核对项逐项自测：说明公共能力的使用约定、兼容性和变更影响，核对构建、性能与静态检查符合约定，未破坏既有能力。完成后在当前角色窗口任务文件和交付物中记录必要信息，使用平台实际窗口 ID 与已确认的协作对象衔接，进入验收。

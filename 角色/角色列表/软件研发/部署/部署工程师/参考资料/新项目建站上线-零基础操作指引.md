# 新项目建站上线 · 零基础操作指引（以腾讯云为例）

> **这是部署工程师的角色参考资料**：跨项目通用，不针对某个具体项目。
> **适用场景**：为新项目办域名/服务器/ICP 备案/解析/部署/上线时，一步步引导零基础用户（或自己照着做）时查阅。
> **唯一权威副本＝本文件**；项目文档如需引用只登记本入口，不复制正文（避免两份内容漂移）。
> 界面偶尔改版：按钮文字不一致时找意思相同的那个；改用阿里云/华为云等厂商时，平台操作部分需按该厂商界面重新核对。

> **怎么用这份文档**：从头往下按顺序做，每步都写了"打开哪个网址 → 点哪里 → 填什么 → 成功什么样 → 出错怎么办"。
> 腾讯云界面偶尔改版，如果按钮文字和我写的不完全一样，**找意思相同的那个按钮**即可。
> 全程要准备：手机、身份证、营业执照（公司/个体户备案用）、邮箱、微信或支付宝（付款）。

# 第 0 步：开工前先想清楚 3 件事

| 想什么 | 为什么 |
|---|---|
| **网站给谁看、干什么用** | 决定买什么配置（纯展示站很便宜） |
| **主体是个人还是公司/个体户** | 决定备案材料完全不同（公司要营业执照，个人只要身份证） |
| **网站名字叫什么** | 备案要填"网站名称"，且不能乱起（见第 4 步说明） |

**顺序记住一句话**：**先买域名 → 再买服务器 → 立刻提交备案 → 备案审核期间去做开发 → 备案通过就上线**。
> ⚠️ 备案要 1~3 周，是全程最慢的一环。别等开发完了才去买域名，那要白等三周。

# 第 1 步：注册腾讯云账号 + 实名认证（约 10 分钟）

## 1.1 注册

1. 打开浏览器，输入网址：**https://cloud.tencent.com**
2. 点页面**右上角「注册」**（或"免费注册"）
3. 选注册方式：
   - **微信扫码**（最快）：用手机微信扫屏幕上的二维码 → 手机上点"允许"
   - 或选"邮箱注册/手机号注册"，按提示填
4. 按提示设置账号密码（建议记在手机备忘录里）

## 1.2 实名认证（必须做，不做不能买域名和服务器）

1. 打开 **https://console.cloud.tencent.com/developer**
2. 找页面上的「**实名认证**」（或用右上角头像 → 账号信息 → 实名认证）
3. 选择认证类型：
   - **公司/个体户备案 → 选「企业认证」**
   - **个人备案 → 选「个人认证」**
4. 企业认证要填：
   | 栏目 | 填什么 |
   |---|---|
   | 企业名称 | 与营业执照**一字不差**的名称（个体户要带"（个体工商户）"后缀） |
   | 统一社会信用代码 | 营业执照上那串 18 位代码 |
   | 法定代表人姓名 | 营业执照上的经营者/法人姓名 |
   | 法定代表人身份证号 | 法人身份证号 |
   | 行业 | 随便选个贴近的（如"互联网信息技术服务"） |
5. 验证方式：一般选「**企业法人微信扫码认证**」→ 让法人本人用微信扫码 + 人脸识别
   - 若法人不方便扫码：可选「企业打款验证」→ 腾讯云给你公司账户打一笔几毛钱，你查到金额后回填
6. **成功标志**：账号信息页面显示「**已认证**」，并显示你的企业/个人名称

> **出错常见**：法人扫脸总失败 → 换"企业打款验证"；企业名称填错 → 必须重开认证（所以照抄营业执照最省事）。

# 第 2 步：买域名（约 10 分钟 + 等实名 1~3 天）

## 2.1 挑域名并下单

1. 打开：**https://console.cloud.tencent.com/domain**
2. 页面上方搜索框输入你想要的域名（例如 `mystudio.com`）→ 点「**查询**」
3. 看到结果后：
   - 显示"可注册" → 点右边的「**加入清单**」
   - 想要多个就加多个，然后点「**立即购买**」（或"去结算"）
4. 进入订单页面，逐个填：
   | 栏目 | 怎么填 |
   |---|---|
   | **域名信息模板**（最重要） | 点「**新建信息模板**」→ 类型选「**企业**」（公司/个体户）→ 填企业名称、统一社会信用代码、上传**营业执照照片**、填联系人/邮箱/手机号 → 提交（审核几分钟到 1 天） |
   | 购买年限 | 选 **1 年**（预算够建议 2~3 年，省得年年续） |
   | 是否开启隐私保护 | 免费版通常默认开，保持默认即可 |
5. 勾选同意协议 → 点「**提交订单**」→ 付款（微信/支付宝）

> ⚠️ **信息模板的所有者，必须和以后备案的主体一致**（企业备案就用企业模板）。这一步搞错，后面备案会被驳回。

## 2.2 提交域名实名认证（不做没法备案）

1. 回到 **https://console.cloud.tencent.com/domain** → 「**我的域名**」
2. 找到刚买的域名，如果状态是「**未实名认证**」，点它 → 「**提交实名认证**」
3. 选择你刚建好的**信息模板** → 确认提交
4. **等 1~3 天**（腾讯云审核 + 注册局审核）
5. **成功标志**：域名列表显示「**已实名认证**」

> **出错常见**：实名失败 → 90% 是证件照片模糊、边角缺失，或名称与证件不一致。重拍重传即可。

# 第 3 步：买服务器（约 10 分钟）

## 3.1 买

1. 打开：**https://console.cloud.tencent.com/lighthouse**（轻量应用服务器）
2. 点「**新建**」/「**购买**」
3. 依次选：
   | 选项 | 选什么 | 为什么 |
   |---|---|---|
   | **地域** | **必须选中国大陆**（北京/上海/广州） | 只有大陆服务器能备案；香港/境外**不能备案** |
   | 套餐规格 | 纯展示站：**2核2G** 或 **4核4G** | 够用且便宜 |
   | 镜像 | 「系统镜像」→ **Ubuntu 22.04 LTS**（或 TencentOS） | 通用、教程多 |
   | 系统盘 | 默认（40~50GB） | 静态站用不完 |
   | **时长** | **1 年**（至少 3 个月） | 备案硬要求：包年包月 ≥3 个月 |
   | 数量 | 1 | — |
4. 付款

## 3.2 买完 5 分钟内必须做的 3 件事

**① 记下公网 IP**
- 打开 **https://console.cloud.tencent.com/lighthouse/instance/index**
- 找到你的实例，**把"公网 IP"抄到手机备忘录**（后面部署、解析都要用）

**② 设置登录方式（用密钥，别用密码）**
- 左侧菜单点「**SSH 密钥**」→ 点「**创建密钥对**」
- 两种方式：
  - 「**自动创建**」：腾讯云生成密钥 → **必须立刻下载私钥文件**（只给这一次，丢了只能重来）→ 存到电脑（如 `D:\密钥\`）
  - 「**使用已有公钥**」：粘贴你自己的公钥（名称只能字母/数字/下划线，例如 `my_deploy_key`）
- 创建后回到实例 → 「**SSH 密钥**」页签 → 「**绑定密钥**」→ 勾选刚创建的密钥 → 确定
- 如果提示需要关机才能绑定 → 让它关机绑完再开机（空服务器没影响）

**③ 放行端口**
- 实例详情页 → 「**防火墙**」页签 → 「**添加规则**」
- 加两条：
  | 协议 | 端口 | 来源 | 策略 |
  |---|---|---|---|
  | TCP | 80 | 留空（＝全部） | 允许 |
  | TCP | 443 | 留空（＝全部） | 允许 |
- ⚠️ **不要点"一键放通"**（会把 3389 等不必要端口也打开，增加被攻击风险）

**成功标志**：实例状态显示「**运行中**」，并且能用密钥登录（登录方法见第 6 步）。

# 第 4 步：提交 ICP 备案（最慢，请第一时间做）

## 4.1 进备案系统

1. 打开：**https://console.cloud.tencent.com/beian**
2. 第一次进入会弹「**服务授权**」→ 点「**同意授权**」（只是允许备案系统读取你的云资源，无费用）
3. 弹「隐私说明/协议」→ 点「**同意并继续**」
4. 在首页输入你的域名 → 点「**去备案**」→ 再点「**新增备案**」

## 4.2 第 1 步：验证备案类型（填这些）

| 栏目 | 填什么 |
|---|---|
| 信息填写方式 | 勾选「**复用腾讯云账号信息填写**」（自动带出主体信息，最省事） |
| **备案区域** | 选**主体所在省**（＝营业执照上的地址所在省，如"河北省/唐山市/玉田县"） |
| **主办单位性质** | 企业/个体户 → 选「**企业**」（页面会提示：个体工商户有字号用企业名称备案） |
| 证件类型 | 「**统一社会信用代码证**」 |
| 上传证件 | 上传**营业执照**照片（四角完整、清晰） |
| 主办者名称 / 证件号 | 自动带出（核对是否与营业执照一字不差） |
| 法定代表人 / 证件号 | 自动带出（核对） |
| 域名 | 填你的**主域名**（如 `mystudio.com`，不带 www） |
| 云资源 | 选你刚买的那台服务器（IP 自动带出） |
| 点「**下一步**」 | — |

## 4.3 第 2 步：主体信息
大部分自动带出，检查：单位地址、详细地址、法人手机号、邮箱。缺的补上 → 下一步。

## 4.4 第 3 步：互联网信息服务（网站信息）

| 栏目 | 填什么 |
|---|---|
| 网站名称 | 与你的业务相关的规范名称（一般用公司简称/品牌名；**别用"中国""国家""XX网"这类**，容易被驳回） |
| 网站服务内容 | 按实际选（展示型官网一般选「其他」或「单位门户网站」） |
| 网站语言 | 中文 |
| 网站负责人 | 一般＝法人本人（姓名/身份证/手机号/邮箱） |
| 前置审批 | 选「**无**」（新闻、出版、医疗、药品等才需要） |
| 点「下一步」 | — |

## 4.5 第 4 步：补充材料
系统会提示传什么就传什么（一般：身份证正反面、手持身份证照，个别省份要签承诺书拍照）。

## 4.6 第 5 步：预览并提交
逐页核对 → 点「**提交**」。

## 4.7 提交之后会发生什么（重要）

| 阶段 | 时长 | 你要做什么 |
|---|---|---|
| ① 腾讯云初审 | 1~2 个工作日 | **保持手机畅通**！初审员可能打电话核实（问公司名、网站用途），答不上会被退回 |
| ② 工信部短信核验 | 24 小时内必须完成 | 手机会收到工信部短信 → 按短信里的网址（beian.miit.gov.cn）或提示**完成核验**（超时要重来） |
| ③ 管局审核 | **1~3 周** | 什么都不用做，等短信/站内信 |
| ④ 通过 | — | 收到通知，拿到**备案号**（形如 `冀ICP备2026XXXXXX号-1`） |

## 4.8 备案期间的禁忌

- ❌ **别把域名解析到服务器并对外开放**（可能被要求整改，甚至驳回）
- ✅ 但可以：把网站部署到服务器上，用**服务器 IP** 访问测试，或只在自己电脑改 `hosts` 文件测试

## 4.9 常见驳回原因

| 提示 | 怎么改 |
|---|---|
| 域名所有者与主体不一致 | 域名信息模板改成与备案主体一致（企业用营业执照），必要时过户 |
| 网站名称不规范 | 换成公司名/品牌名，别带"中国/国家/官网"等字样 |
| 证件照片不清晰 | 重拍（原件拍摄，四角完整，别用复印件/翻拍屏幕） |
| 主体信息与证件不一致 | 照营业执照逐字核对重填 |

# 第 5 步：域名解析（备案通过后做）

1. 打开：**https://console.cloud.tencent.com/cns**（云解析 DNS）
2. 你的域名应已在列表 → 点「**解析**」
3. 点「**添加记录**」，填第一条：
   | 栏目 | 填什么 |
   |---|---|
   | 主机记录 | `@`（代表主域名） |
   | 记录类型 | `A` |
   | 线路类型 | 默认 |
   | 记录值 | 你的**服务器公网 IP** |
   | TTL | 600（默认） |
   → 点「确认」（可能要求微信扫码验证身份）
4. 再点「**添加记录**」加第二条：主机记录填 `www`，其余同上（若想 `www.域名` 也能开）
5. **验证是否生效**（在电脑上）：
   - 按 `Win+R` → 输入 `cmd` → 回车
   - 输入：`nslookup 你的域名` → 回车
   - 看到**你服务器的 IP** 就说明生效了（一般几分钟~几小时，最慢 48 小时）

> **小建议**：决定一个"正式地址"（带 www 或不带），另一个做 301 跳转，别两个都当正式地址（否则搜索引擎会认为是两个网站）。

# 第 6 步：部署网站（把文件放上去、开 HTTPS）

> 这步技术性最强。**零基础推荐用"宝塔面板"（图形界面，鼠标操作）**；有命令行基础的可以走 B 方案。

## 方案 A：宝塔面板（零基础友好）

1. **连服务器**
   - Windows 电脑：按 `Win+R` → `cmd` → 回车，输入（把路径和 IP 换成你的）：
     ```
     ssh -i D:\密钥\你的私钥文件 ubuntu@你的服务器IP
     ```
     （首次会问 yes/no，输入 `yes` 回车）
   - 登录成功会看到类似 `ubuntu@VM-0-6-ubuntu:~$` 的提示符
2. **安装宝塔面板**（在服务器里粘贴执行，一路回车）：
   ```
   curl -sSO https://download.bt.cn/install/install_lts.sh && sudo bash install_lts.sh
   ```
   装完屏幕会显示：**面板地址、用户名、密码**（抄下来！）
3. **在浏览器打开面板地址** → 输入用户名密码登录
   - 首次会推荐安装套件 → 选「**Nginx**」（其他不用）
4. **上传网站文件**：左侧「网站」→ 添加站点 → 域名填你的域名 → 建好后进入站点目录 → 用「上传」把网站文件（`dist` 里的内容）传进去
5. **开 HTTPS**：站点设置 → 「SSL」→ 「Let's Encrypt」→ 勾选域名 → 申请（免费，自动续期）

## 方案 B：命令行（照抄即可）

在服务器上依次执行（`$` 开头的不用输，只是提示符）：

```bash
# 1) 装 Nginx
sudo apt update && sudo apt install -y nginx

# 2) 建站点目录
sudo mkdir -p /var/www/你的站点名

# 3) 把网站文件传上去（在【你自己电脑】上执行，不是服务器）
#    下载 WinSCP 或 FileZilla，用 SFTP 连接：主机=服务器IP，用户名=ubuntu，密钥=你的私钥
#    然后把 dist 文件夹里的内容拖到 /var/www/你的站点名/ 下
#    （也可在服务器上建目录：sudo mkdir -p /var/www/xxx/releases/20260917-1）

# 4) 写 Nginx 配置（把域名换成你的）
sudo tee /etc/nginx/conf.d/你的站点名.conf > /dev/null <<'EOF'
server {
    listen 80;
    server_name 你的域名 www.你的域名;
    root /var/www/你的站点名;
    index index.html;
    location / { try_files $uri $uri/ /index.html; }
}
EOF

# 5) 检查并生效
sudo nginx -t && sudo systemctl reload nginx

# 6) 申请免费 HTTPS 证书（自动续期）
sudo apt install -y certbot
sudo certbot certonly --webroot -w /var/www/你的站点名 -d 你的域名 -d www.你的域名 \
     --non-interactive --agree-tos --register-unsafely-without-email \
     --deploy-hook "systemctl reload nginx"
# 然后把上面 Nginx 配置里的 80 改成 443 ssl，并加上证书路径（certbot 会提示位置）
```

## 发布更新怎么发（以后每次改版）

```
本地改代码 → 出构建产物 → 传到服务器新版本目录 →
切换软链：sudo ln -sfn /var/www/站点名/releases/新版本 /var/www/站点名/current →
sudo systemctl reload nginx
```
**回滚**：把软链指回上一个版本目录，reload，几秒钟回到旧版。

# 第 7 步：上线自检（逐项打勾）

- [ ] 浏览器打开 `https://你的域名` → 页面正常显示
- [ ] 手机打开同一个网址 → 显示正常（若是响应式/手机版）
- [ ] 地址栏有小锁（HTTPS 生效），`http://` 会自动跳 `https://`
- [ ] **页脚显示 ICP 备案号**，点它能进工信部网站
- [ ] 页面没有方括号占位、没有"待补充"字样
- [ ] 联系方式（电话/微信/邮箱）是当前有效的
- [ ] 重启服务器后网站仍能打开（测自动恢复）
- [ ] 证书到期时间记一下（Let's Encrypt 90 天，已配自动续期）

# 第 8 步：公安联网备案（上线后 30 日内，免费）

## 8.1 注册账号

1. 打开：**https://beian.mps.gov.cn**（全国互联网安全管理服务平台）
2. 点「**用户登录**」→ 弹窗点「**跳转**」（跳到公安部政务服务平台）
3. 点「**注册账号**」→ 选「**个人用户注册**」（官方明确：个人账号可为任意性质主体办理业务）
4. 填手机号 + 验证码 + 密码 → 完成实名认证
5. 注册完登录 → 自动跳回备案平台（若没跳回，手动再输一次 `https://beian.mps.gov.cn`）

## 8.2 先提交"开办主体"

1. 顶部菜单「**业务办理**」→ 找「**开办主体管理**」/「新增主体」
2. 填：
   | 栏目 | 填什么 |
   |---|---|
   | 主体类型 | 单位（企业单位）/ 个人 |
   | 主办单位名称 | 与营业执照一字不差 |
   | 证件类型 | 统一社会信用代码证 |
   | 证件号 | 营业执照上的 18 位代码 |
   | 主办单位有效证件 | 上传**营业执照**照片 |
   | 单位办公地址 | 营业执照地址（省/市/县 + 详细地址） |
   | 法定代表人姓名 | 法人姓名 |
   | 负责人信息 | 一般同法人：姓名/证件/手机号/邮箱 |
   | 认证方式 | 选「文件认证」→ 上传**身份证人像面、国徽面、手持身份证**三张照片 |
3. 提交

## 8.3 再提交"新办网站申请"

1. 菜单「**网站业务**」→「**新办网站申请**」
2. 分 4 步（页面上有 01/02/03/04 提示）：
   - **01 开办主体**：多数自动带出，核对
   - **02 网站基本信息**（逐栏）：
     | 栏目 | 填什么 |
     |---|---|
     | 网站名称 | 同 ICP 备案的网站名称 |
     | 是否有工信部备案号 | 选「是」 |
     | 工信部备案号 | 你的 `XXICP备XXXXXXXX号-1` |
     | 网站开通日期 | 网站实际上线那天 |
     | 主域名 | 你的域名（不带 www） |
     | 域名证书 | **上传域名证书图片**（去哪下：域名注册控制台 → 我的域名 → 域名详情 → 「域名证书」下载，PDF 可截图） |
     | 域名证书有效期 | 证书上写的起止日期 |
     | IP | 服务器公网 IP |
     | 接入商所属地区管辖 | 境内 |
     | 接入商所属地区 | 先选省再选市（云厂商注册地，如"北京市/北京市"）→ 选完"接入商名称"下拉才有内容 |
     | 接入商名称 | 云厂商的接入主体名（示例：`腾讯云计算（北京）有限责任公司`） |
     | 网站接入方式 | 选「云主机」（没有就选"租赁虚拟主机"） |
     | 域名服务商所属地区 / 名称 | 同上（域名在哪注册就填哪家） |
     | 是否提供互联网交互服务 | 纯展示站选「否」（有留言/评论/注册/上传才选"是"） |
     | 网站类型 | 树形勾选，按实际（展示型官网常选"信息咨询类"或"其他"） |
     | 是否提供涉及管制物品信息发布服务 | 选「否」 |
     | 相关前置许可 | 选「否/无」 |
   - **03 网站负责人信息**：姓名/证件/手机/邮箱 + 认证方式（文件认证要再传一次身份证三张照片）
   - **04 网站安全负责人 + 应急联络人**：可都填同一人（也要各自的身份证照片）
3. 提交 → 等属地公安网安审核（官方口径 30 天内）
4. **通过后**：拿到**公安备案号**（形如 `冀公网安备XXXXXXXX号`）→ **挂到网站页脚**（与 ICP 备案号并排）

# 附一：费用与时间预估（第一年）

| 项 | 费用 | 时间 |
|---|---|---|

| 服务器（大陆轻量 2核2G~4核4G） | 100~300 元/年 | 即时 |
| ICP 备案 | 0 元 | **1~3 周（最慢）** |
| HTTPS 证书 | 0 元 | 10 分钟 |
| 公安备案 | 0 元 | 提交 1~2 小时，审核 ≤30 天 |
| **合计** | **约 200~400 元/年** | 从买到上线：**最快 1~2 周**（全卡在备案） |

# 附二：8 个最常见的坑

1. 域名所有者 ≠ 备案主体 → 备案驳回（用营业执照建信息模板）
2. 服务器只买 1 个月 → **不能备案**（必须 ≥3 个月）
3. 服务器买香港/境外 → **不能备案**
4. 备案期间把域名解析上线 → 可能被要求整改/驳回
5. 备案号没挂页脚 → 管局责令整改
6. 上线后忘了公安备案（30 日内）→ 逾期
7. 云防火墙只放 80，忘了 443 → HTTPS 打不开
8. 初审电话没接/答不上来 → 备案被退回（提交后保持手机畅通）

# 附三：名词对照（看不懂术语时翻这里）

| 词 | 大白话 |
|---|---|
| 域名 | 网站地址，如 `abc.com` |
| 服务器 | 24 小时开机的一台电脑，网站文件放在它上面 |
| 备案（ICP） | 工信部要求：网站开办前登记主体和域名信息 |
| 公安备案 | 公安部门要求：网站开通后 30 日内登记 |
| 解析 | 把域名"指向"服务器 IP 的动作 |
| A 记录 | 解析记录的类型，把域名指向一个 IP |
| 防火墙 | 控制"哪些端口能被外部访问"的开关 |
| 端口 80 / 443 | 80＝普通网页（http）；443＝加密网页（https） |
| HTTPS 证书 | 让浏览器地址栏出现小锁、数据传输加密的东西 |
| SSH 密钥 | 登录服务器用的"钥匙文件"，比密码安全 |
| 软链（符号链接） | 像 Windows 的快捷方式，切一下就能换生效版本 |

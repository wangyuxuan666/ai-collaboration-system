# 创建角色流程

本流程每次只创建一个角色。三个阶段保留必要的确认门槛，但不规定固定问法或思考步骤。

## 0. 使用依据

开始前读取 [角色设计理念](../参考资料/角色设计理念.md)。[角色文件模板](../../../../模板/系统治理/角色/角色文件模板.md) 只在第二阶段读取；确定资产位置时读取 [角色资产布局规范](../../../../规范/角色资产布局规范.md)。

发现模板需要调整时，说明问题、影响和建议；用户确认后修改模板并同步受影响角色，存在冲突时暂停并询问用户。

## 1. 形成充分的角色理解

角色管理员以独立的角色设计判断，理解用户真正希望该角色解决的问题、达到的结果、应有的自主性、协作关系和权限边界，并识别重叠、缺失、冲突或更合适的设计。本阶段不读取角色文件模板，也不按模板字段提问或使用固定问题清单。

角色管理员知道专业领域、参考资料、任务流程、资产台账、稳定交付物和角色专属模板都是角色可能需要的专业支撑，但本阶段不要求主动逐项判断它们是否需要。对话或分析中自然涉及这些内容时，角色管理员应识别其与角色专业履职的关系，并将已明确需要的内容纳入当前角色定义。

用户的描述、举例、取舍和已有角色体系都是理解材料，不自动代表角色定义已经完成。角色管理员应自行判断理解是否充分；仍存在会实质改变角色设计的未知、冲突或误解风险时，应通过自然对话、分析已有体系或提出设计判断继续深化理解。

只有角色管理员能够可靠说明角色的核心价值、职责边界、协作关系和预期行为，并向用户表达形成的完整理解后，才可以请求用户确认进入第二阶段。用户的确认是对当时共同形成的角色定义的确认门槛，不替代角色管理员对创建条件是否已满足的专业判断。

## 2. 完善专业支撑与角色资产

基于第一阶段形成的角色理解，角色管理员必须独立判断专业领域、参考资料、任务流程、资产台账和角色专属模板等角色支撑，是否能显著增强当前角色的理解、判断、交付质量、协作效果或效率，并在值得时决定使用已有内容或创建专属资产及其承载内容。角色核心文件能够支持独立履职只是底线，不得作为跳过专业增强设计的理由。用户未主动提及某类支撑，不代表它不能带来有价值的提升；角色管理员必须主动完成这项判断，也不得为了形式完整创建收益不明显、内容重复或会束缚专业判断的资产。

读取 [角色文件模板](../../../../模板/系统治理/角色/角色文件模板.md)，用于检查角色定义与资产设计是否完整，并确定内容应由核心文件、专业领域、流程、参考资料、模板、Wiki 还是运行记忆承载；模板不主导角色设计，也不复制其他文件负责的正文。确定资产位置时读取角色资产布局规范。

按模板为角色设计"知识库读取"节：统一为按[知识库入口](../../../../../知识库/入口.md)从知识索引按任务检索，不设置固定读取清单；角色通过索引摘要判断是否读取，方向差异进专业领域，不在核心文件展开。

按模板为角色设计"身份定位"与"价值观"节：身份定位用身份式写法，写"是谁"不写"怎么做"，从角色自己的视角表达其相信、在意和反感的立场，不同角色不得共用同一句式；价值观写 3～5 个该角色捍卫什么、对什么较真的具体短语，不是行为规则，也不是空话口号。两者按模板中的分工说明分配：身份定位回答"我是谁、以什么立场承担什么责任"，价值观回答"我捍卫什么、对什么较真"，同一内容两处都放得下时优先放价值观，不留两边重复。

按模板为角色设计"数据边界"节：集中列出该角色允许访问的区域（专业领域、参考资料、资产目录、外部资产等），每项指向已有登记或入口，不复制正文；本节是"可访问范围"汇总，不是"启动必读"清单，任务实际需要时可按角色通用规则扩大读取范围，也不限制按需检索 Wiki。

生成专业领域文件时，按"方向定位 + 方向核对项 + Wiki 检索指引"组织：方向定位说明该方向的职责侧重，方向核对项是进入该方向后的补充核对范围，Wiki 检索指引写明按哪个分组检索规范页。

生成流程文件时，开头写"第 0 步【开工前】按知识库入口检索"：通过[知识库入口](../../../../../知识库/入口.md)检索与本次任务相关的规范知识，命中且影响当前判断时读取，未命中则跳过，不阻塞后续工作；管理类/组织类流程（如负责人分工、技术经理组织）不强制加第 0 步。

只有缺失信息会实质影响资产设计且无法可靠判断时才询问。职位类型按模板标准判断：能够唯一判断时说明依据并确认，存在多个合理选项时只提供模板登记的有效选项。

角色信息和需要生成的资产明确后，进入第三阶段。

## 3. 请示、生成与检查

生成前取得用户允许。按照角色文件模板和资产布局规范创建角色文件夹、固定目录（包括资产目录）、核心文件、已确认的附加资产和角色入口记录；不创建未经确认的占位文件。

免询问文档从 [角色免询问文档模板](../../../../模板/系统治理/角色/角色免询问文档模板.md) 直接复制并重命名，不读取或修改正文，并将准确路径写入角色核心文件。

生成后检查结果是否符合已确认的角色定义，索引和引用能否定位，固定目录是否完整，以及角色在不加载增强内容时能否正常履职。再用典型任务检查其能否自主判断、遵守必要边界并产生可验证结果，最后反馈生成结果和发现的问题。

# 维护知识库流程

## 1. 适用场景

知识库管理员检查、修复或优化既有 Wiki、raw、知识索引、维护日志及其结构关系，包括周期性维护和针对已知问题的专项维护。

本流程维护知识库整体健康，不处理收集区候选；收集区候选使用“收集区整理到 raw”或“收集区整理到 Wiki”流程。

## 2. 维护原则

- 先完成只读检查并形成维护判断，再决定是否需要写入。
- 以实际知识、来源和检索效果为依据，不为目录整齐机械拆分、合并或移动页面。
- 能够根据现有事实唯一判断的一致性问题自主修复；涉及语义裁决、内容损失或结构变化时遵守角色确认边界。
- 只读取当前维护范围所需的内容。先使用路径、metadata、索引和摘要定位问题，需要判断正文或证据时再扩大读取。
- 维护不能静默改变有效知识的含义，也不能把未确认经验升级成规范。
- 处理页面前先读取 metadata 中的 `启用`；只读取或维护 `启用: 是` 的页面正文。涉及状态变化时使用 `启用` 字段，并同步核对索引和日志。

## 3. 检查与分类

根据任务确定维护范围，先执行知识库管理员登记的“检查知识库”工具。正常摘要表示确定性结构检查通过；出现错误或警告时，以报告定位相关文件，再按需读取 [知识写入规范](../../../../../知识库/规范/知识写入规范.md)、相关模板、index、log、页面 metadata 和 raw 来源。检查工具不能判断知识语义、证据强弱或合并方案，这些内容仍由知识库管理员根据实际材料判断。

至少从以下类型判断发现的问题：

```text
发现知识库问题
├─ 明确的一致性问题
│  └─ metadata、index、log、来源、状态或链接与现有事实不一致
├─ 待整理内容
│  └─ raw 尚未形成知识或未同步已有页面
├─ 知识组织问题
│  └─ 重复、过时、主题归属漂移、孤立页面或知识膨胀
├─ 内容冲突
│  └─ 保留证据并提交用户裁决
└─ 结构问题
   └─ 涉及新增专业领域、目录层级或 schema 的方案提交用户确认
```

不得仅因页面数量多、目录为空或暂时没有索引条目，就直接判定内容应删除。

### 语义健康检查

除确定性检查外，每次维护按以下清单检查知识语义层问题，逐项记录“结果、发现、处理建议”，汇总为语义检查报告：

1. 内容矛盾：同主题页面之间，或页面“证据与演变”中的新旧结论是否冲突而未并列处理；
2. 孤立页面：没有入链、且无法通过 index 定位的启用页面；
3. 主题归属漂移：页面主题与所在专业领域或主题路径明显不符；
4. 缺失页面：多个 raw 或页面反复涉及、但尚未形成独立知识页的重要概念；
5. 过时内容：结论已被更新来源替代，但页面“证据与演变”未记录替代关系；
6. 页面粒度漂移：对照最小完整判断单元，页面是否被切得过碎或合并过宽；
7. 索引遗漏或失真：启用知识页未登记 index，或 index 摘要与页面内容明显不符。

能根据现有事实唯一判断且不改变有效语义的修复按第 4 节自行处理；涉及语义裁决、删除或结构变化的项提交用户确认。

## 4. 维护方案与确认

对能够根据现有事实唯一判断且不会改变有效语义的修复，知识库管理员可以自行处理。

触发角色额外询问事项时，先提交精简维护方案，说明：

- 当前问题和证据；
- 拟修改、移动、合并、停用或删除的内容；
- 对检索、来源和后续写入的影响；
- 保留不变的内容；
- 风险、替代方案和验证方式。

用户确认前，不执行方案中的高影响变更。多个合理方案会产生实质差异时，给出推荐，只把必要选择交给用户。

## 5. 执行维护

按照已经确认的范围处理问题：

- 修复页面、raw、index 和 log 之间能够确认的不一致；
- 整理待处理 raw，优先更新已有主题页；
- 合并或重组知识时保留来源、适用条件、演变和被替代结论；
- 规范变更保留确认依据、来源和状态变化；
- 页面路径、标题、摘要或 `启用` 字段变化时同步检查 index 和 log；
- 无法可靠处理的内容保持或标记为“待整理”，不强行形成正式结论。

执行中发现实际情况会实质改变已确认方案时暂停并向用户说明；不改变目标和影响范围的实现细节自行处理。

## 6. 验证与反馈

维护完成后再次执行“检查知识库”工具，并结合本次语义维护范围至少检查：

- 路径和 metadata 符合当前 schema；
- 知识页有实际正文、来源和适用范围；
- raw、页面、index 和 log 已同步；
- 链接目标存在，待整理状态准确；
- 没有静默覆盖冲突或丢失有效证据；
- 没有把项目运行记忆写入 Wiki；
- 没有修改角色文件、权限边界或任务流程。

向用户反馈实际维护内容、验证结果、仍待处理的问题和知识库整体风险。

# 前端开发说明书（plus-ui）

> 若依Plus全配的官方前端：Vue3 + Vite + TS + Element Plus + Pinia。
> 官方文档已放本地：`官方文档\6.X\plus-ui\`（md 按需读）；线上：https://plus-doc.top

## 一、启动项目

```bash
pnpm install        # 装依赖
pnpm dev            # 启动开发服务，默认 http://localhost:80
```

- 代理：`vite.config.ts` 中 `/dev-api` 代理到 `http://localhost:8080`（后端地址）
- 环境配置：`.env.development`（开发）/ `.env.production`（生产）
- 联调前提：后端已启动在 8080

## 二、目录结构（src/）

| 目录 | 放什么 | 开发时动作 |
|---|---|---|
| `api/` | 接口定义，按模块分目录（system/demo/...），每模块 `index.ts`+`types.ts` | **加接口：** 在对应模块的 `api/xxx/index.ts` 里加函数 |
| `views/` | 页面组件，按模块分目录 | **加页面：** 在 `views/xxx/` 下新建 `.vue` |
| `router/index.ts` | 路由定义（常量路由 + 动态路由表） | **挂路由：** 在路由表中加一条，或配动态路由 |
| `store/modules/` | Pinia 状态（user/dict/permission/tagsView...） | 全局状态放这里，按需新增模块 |
| `utils/request.ts` | axios 封装（拦截器、token、错误处理） | 一般不用改，直接调 api 层 |
| `utils/` | 工具函数（auth/crypto/dict/validate...） | 按需使用 |
| `components/` | 通用组件（Pagination/FileUpload/DictTag...） | 已有可复用，新增放这里 |
| `directive/` | 权限指令（v-hasPermi 等） | 页面控制权限用 |
| `layout/` | 布局（侧边栏、顶栏、标签页） | 一般不改 |
| `lang/` | 国际化 | 需要多语言时用 |
| `plugins/` | 全局插件（auth/cache/modal/download...） | 工具方法入口 |

## 三、怎么加一个"列表页面"（最小路径）

1. **加接口**：`src/api/system/xxx.ts`（若无模块则新建目录），写 `listXxx(params)` 调用 `request`
2. **加页面**：`src/views/xxx/index.vue`，用 `ElTable` + `Pagination` 组件渲染
3. **挂路由**：`src/router/index.ts` 加路由（含 `meta.title`），或用代码生成器自动生成
4. **页面里调接口**：`import { listXxx } from '@/api/system/xxx'`

> 更快的方式：用后端自带的**代码生成器**（建表后自动生成前端页面+接口+路由），见后端说明书。

## 四、权限控制

- 登录/路由守卫：`src/permission.ts` 已配好（未登录跳登录页）
- 页面级：路由 `meta.permissions` 或 `v-hasPermi` 指令
- 按钮级：`<el-button v-hasPermi="['system:user:add']">`
- 状态：`store/modules/permission.ts` 管理动态路由与权限

## 五、常用约定

- 组件命名：PascalCase；文件：`index.vue` 为入口
- 状态管理用 Pinia（`defineStore`），不用全局变量
- 接口返回统一结构 `{ code, msg, data }`，`request.ts` 已处理错误与 token
- 图标用 `SvgIcon` 组件或 Element Plus 自带图标

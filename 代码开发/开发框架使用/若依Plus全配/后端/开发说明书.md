# 后端开发说明书（RuoYi-Vue-Plus）

> 若依Plus全配的官方后端：Spring Boot 4.1 + JDK21 + MyBatis-Plus + Sa-Token。
> 官方文档已放本地：`官方文档\6.X\ruoyi-vue-plus\`（md 按需读）；线上：https://plus-doc.top

## 一、环境要求

- JDK 21（本机已装）、Maven 3.6+
- MySQL 5.7+/8.x（默认库）、Redis ≥ 6（必装，登录/缓存依赖）
- 前端代理指向本服务 8080 端口

## 二、启动项目

```bash
# 1. 建库导数据（MySQL，默认库名 ry-vue）
#    执行 script/sql/ 下的 SQL：ry_vue.sql（主库）、ry_job.sql（定时任务，可选）、ry_workflow.sql（工作流，可选）、ry_ai.sql（AI，可选）

# 2. 改数据库连接（默认 root/root，库 ry-vue）
#    ruoyi-admin/src/main/resources/application-dev.yml

# 3. 启动 Redis（本机 127.0.0.1:6379）

# 4. 启动服务（两种方式任选）
cd ruoyi-admin && mvn spring-boot:run
# 或 IDE 中运行 org.dromara.DromaraApplication

# 5. 验证：http://localhost:8080 返回服务信息
```

## 三、目录结构

```
后端/
├─ ruoyi-admin/       # 启动模块（配置文件 application*.yml 在这里）
├─ ruoyi-common/      # 公共模块（工具、异常、常量、基类）
├─ ruoyi-modules/     # 业务模块
│  ├─ ruoyi-system/   # 核心业务：用户/角色/菜单/字典/日志 等
│  ├─ ruoyi-gen/      # 代码生成器
│  ├─ ruoyi-job/      # 定时任务
│  ├─ ruoyi-workflow/ # 工作流
│  └─ ruoyi-demo/     # 示例模块（新业务参考它）
├─ ruoyi-api/         # 对外接口定义
├─ ruoyi-extend/      # 扩展包
└─ script/sql/        # 数据库初始化脚本
```

## 四、模块内分层（以 ruoyi-system 为例）

```
controller/   # 接口入口（@SaCheckPermission 控制权限）
service/      # 业务逻辑（接口 + impl 实现）
mapper/       # 数据访问（MyBatis-Plus）
domain/       # 实体（bo=入参对象、vo=出参对象）
```

- 实体用 `bo`（接收参数）/ `vo`（返回数据）区分，**不直接暴露 Entity 给前端**（知识库规范）
- 返回统一结构 `{ code, msg, data }`，异常由全局处理器统一兜底

## 五、怎么加一个"新模块"（最小路径）

1. **建表** → 执行建表 SQL 到数据库
2. **代码生成**：用内置代码生成器（前端页面操作：系统→代码生成），自动生成 controller/service/mapper/domain + 前端页面
3. **或手动写**：参考 `ruoyi-demo` 模块，按 controller → service → mapper → domain 顺序新增
4. **配置权限**：Controller 方法上加 `@SaCheckPermission("system:xxx:list")`，并在菜单管理中授权

## 六、常用约定

- 主键：雪花 ID（无需自增配置）
- 分页：MyBatis-Plus 分页插件，入参 `pageNum/pageSize`
- 数据权限：Mapper 注解（部门/角色过滤），默认已配置
- 缓存：Spring-Cache 注解（`@Cacheable` 等），Redis 存储
- 日志：`@Log` 注解记录操作日志
- 接口加密：前后端默认开启 AES+RSA 加密传输（`.env.development` 与后端对应），**改密钥须前后端一起改**

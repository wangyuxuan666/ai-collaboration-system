# 抖音小程序开发说明书

> 原生抖音小程序骨架（**TypeScript**，按抖音官方 TS 升级方案搭建）。**后端用纯净骨架后端**（共用，见 `纯净骨架\后端\开发说明书.md`），登录走 `miniapp-login` 接口。

## 一、运行项目

1. 抖音开发者工具 → 导入项目 → 选择 `frontend\` 目录
2. 替换 `project.config.json` 的 appid（骨架用 testappid 占位）
3. 首次使用先装类型声明（IDE 构建 npm 或命令行）：
   ```bash
   cd frontend && pnpm i
   ```
4. 改 `utils/config.ts` 的 `baseUrl`：开发连本地后端 `http://localhost:8080`；真机/生产改 https 域名（并在抖音后台配 request 合法域名）
5. 开发阶段如连本地，开发者工具需关闭"域名校验"

## 二、目录结构

```
frontend/
├─ app.ts / app.json / app.ttss   # 入口、全局配置、全局样式
├─ project.config.json            # 项目配置（appid；setting.useCompilerPlugins=["typescript"] 开启 TS）
├─ tsconfig.json                  # TS 配置（官方推荐，types 指向 @douyin-microapp/typings）
├─ package.json                   # 依赖（@douyin-microapp/typings、typescript）
├─ typings/index.d.ts             # 全局类型（IAppOption）
├─ api/                           # 接口层：按业务分文件（auth.ts 示例）
│  └─ auth.ts                     # 登录/用户信息接口
├─ utils/
│  ├─ config.ts                   # 后端地址配置（唯一改的地方）
│  ├─ request.ts                  # 请求封装（token、错误处理、401 跳登录）
│  └─ auth.ts                     # 登录态存取（token 存 storage）
└─ pages/                         # 页面：每页 .ttml/.ttss/.ts/.json
   ├─ index/                      # 首页（示例：展示登录态）
   └─ login/                      # 登录页（tt.login → 后端换 token）
```

## 三、怎么加一个页面（最小路径）

1. **加接口**：`api/xxx.ts` 写请求函数（调 `request`，带返回类型）
2. **加页面**：`pages/xxx/` 下建 `.ttml` `.ttss` `.ts` `.json` 四个文件
3. **注册页面**：`app.json` 的 `pages` 数组加路径
4. **页面里调接口**：`import { listXxx } from '../../api/xxx'`

## 四、登录流程（已配好）

- 登录页 `pages/login/index.ts`：`tt.login()` 拿 code → 调 `POST /api/v1/auth/miniapp-login`（platform=douyin）→ 存 token → 回首页
- 后续请求：`utils/request.ts` 自动带 `Authorization: Bearer <token>` 头
- token 失效（HTTP 401）：自动清登录态 → 跳登录页
- 骨架后端为**模拟登录**（code 直接换 token）；接真实抖音登录时后端换 code2session（见后端说明书）

## 五、接口约定（与后端契约，勿改）

- 响应：`{ code, data, message }`，**code=0 成功**（`request.ts` 已处理，返回业务 data）
- 鉴权：`Authorization: Bearer <token>`
- 401：后端返回 401 → 前端自动跳登录

## 六、常用约定

- 页面文件四件套齐备（.ts/.ttml/.ttss/.json），页面路径注册到 `app.json`
- 接口统一走 `api/` + `utils/request.ts`，不在页面里直接 `tt.request`
- token 只经 `utils/auth.ts` 存取，不散落各处
- 全局配置只改 `utils/config.ts`
- **TS 约定**：接口入参出参定义类型（参考 `api/auth.ts`）；全局类型放 `typings/`；新增文件用 `.ts` 后缀
- 与微信小程序的差异：API 前缀 `tt.`、模板后缀 `.ttml/.ttss`、条件渲染用 `tt:if`——两套代码结构一致，移植时只改这几处

## 七、TS 升级说明（官方方案）

骨架已按[抖音官方 TS 支持文档](https://developer.open-douyin.com/docs/resource/zh-CN/mini-app/develop/dev-tools/developer-instrument/development-assistance/typescript)搭建：
- `project.config.json` 的 `setting.useCompilerPlugins: ["typescript"]`
- 依赖 `@douyin-microapp/typings`（抖音官方类型声明）
- `tsconfig.json` 用官方推荐配置
- 新建 TS 项目时也可在 IDE 创建界面勾选"开发语言：TypeScript"直接生成

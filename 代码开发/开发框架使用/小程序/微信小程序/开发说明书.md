# 微信小程序开发说明书

> 基于 [Weapp-Starter](https://github.com/MatrixCross/Weapp-Starter)（规范化原生微信小程序模板，MIT），已适配纯净骨架后端。
> **后端用纯净骨架后端**（见 `纯净骨架\后端\开发说明书.md`），登录走 `miniapp-login` 接口。

## 一、运行项目

```bash
cd frontend
pnpm i                          # 装依赖
pnpm unocss                     # 生成 UnoCSS 样式（监听 wxml）
# 微信开发者工具：导入 frontend 目录 → 工具-构建 npm → 编译
```

- 替换 `project.config.json` 的 appid
- 改 `src/config.ts`：`defaultApiServer` 后端地址（开发 `http://localhost:8080`；生产 https 域名 + 微信后台配 request 合法域名）
- 开发连本地后端时，开发者工具需勾选"不校验合法域名"

## 二、目录结构（src/）

| 目录 | 放什么 | 开发时动作 |
|---|---|---|
| `apis/` | 接口封装，按业务分文件（`auth.ts` 已含登录） | **加接口：** 在 `apis/` 加文件或函数 |
| `pages/` | 主包页面（index/、login/） | **加页面：** 在 `pages/` 建目录（4 件套），注册到 `app.json` |
| `packages/` | 分包页面（logs/ 示例） | 分包内容放这里 |
| `store/` | 全局状态（MobX） | 全局共享状态放这里 |
| `components/` | 公用组件（svg-icon 示例） | 可复用组件放这里 |
| `utils/` | 工具（request/ 请求封装、storage 缓存、index） | 复用逻辑放这里 |
| `typings/` | TS 类型定义（业务类型按 namespace 拆分） | 类型放这里 |
| `assets/` | 资源（svg/img） | 静态资源放这里 |
| `config.ts` | **全局配置（后端地址唯一改动点）** | 改这里 |

## 三、怎么加一个页面（最小路径）

1. **加接口**：`apis/xxx.ts` 写请求函数（用 `defaultRequest.get/post`）
2. **加页面**：`pages/xxx/` 建 `.ts/.wxml/.wxss/.json` 四件套（页面统一用 `Component` 构建，不用 Page）
3. **注册**：`app.json` 的 `pages` 加路径
4. **调接口**：`import { xxx } from '../../apis/xxx'`

> 参考 `pages/index` 和 `apis/auth.ts` 的写法。

## 四、登录流程（已配好）

- `pages/login/index.ts`：`wx.login()` 拿 code → `POST /api/v1/auth/miniapp-login`（platform=wechat）→ 存 token → 回首页
- 后续请求：`utils/request/defaultRequest.ts` 自动带 `Authorization: Bearer <token>` 头
- token 失效（HTTP 401）：自动清 token → 跳登录页
- 骨架后端为**模拟登录**（code 直接换 token）；接真实微信登录时后端换 code2session（见后端说明书）

## 五、接口约定（与后端契约，勿改）

- 响应：`{ code, data, message }`，**code=0 成功**（`defaultRequest` 已适配，返回 `{isSuccess, code, message, data}`）
- 鉴权：`Authorization: Bearer <token>`（自动带）
- 401：后端返回 401 → 自动跳登录页
- **注意**：模板原始响应格式是 `{code, msg, data}`，已改为 `{code, data, message}` 对齐纯净骨架，勿改回

## 六、常用约定

- 页面统一 `Component` 构建（模板规范）
- 接口统一走 `apis/` + `defaultRequest`，不在页面直接 `wx.request`
- 全局配置只改 `src/config.ts`
- 分包内容放 `packages/`，主包页面放 `pages/`
- TS 类型放 `typings/`，按 namespace 拆分

## 七、技术栈（模板自带）

- TypeScript + ESLint + Prettier + CommitLint + Husky（工程化全配）
- MobX 全局状态 + computed（类 Vue 写法）
- Vant + TDesign 组件库 + UnoCSS（类 Tailwind）
